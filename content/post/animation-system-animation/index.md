## Animation 是什么

`Animation` 窗口用于在 Unity 编辑器中创建、预览和修改 `AnimationClip`。它记录的是对象及其组件属性在不同时间点的值；播放动画时，Unity 会按照这些记录和曲线插值，不断改变对象状态，从而形成动画效果。

简单说，Animation 解决的是“一个对象在一段时间里怎么变化”的问题。

常见用途：

- 制作物体的位移、旋转、缩放动画。
- 制作 UI、材质、颜色、透明度等属性变化。
- 编辑关键帧、动画曲线和动画事件。
- 调整动画片段的循环、采样率、播放模式等参数。

> `Animation` 窗口负责编辑动画片段；运行时通常由 `Animator` 组件和 `Animator Controller` 控制动画播放与状态切换。

## 核心概念

### AnimationClip

`AnimationClip` 是 Unity 动画系统中的基础动画资源，通常保存为 `.anim` 文件。一个动画片段表示一段独立动作，例如开门、跳跃、攻击、按钮淡入、角色待机等。

### 动画时间轴

每个动画片段都有自己的时间范围，从动画开始到动画结束。Animation 窗口右侧的时间轴用于放置关键帧、拖动播放头、查看当前时刻的动画状态。

### 帧率与帧

动画帧率表示一秒被切分成多少帧。假设动画采样率是 `60 FPS`，那么 1 秒包含 60 帧，每帧间隔约为 `1 / 60 = 0.0167` 秒。

需要注意：

- 时间轴可以按秒显示，也可以按帧显示。
- 时间轴上的一格不一定代表 1 秒，具体取决于显示模式和采样率。
- 帧率越高，编辑时的时间精度越细，但不等于运行时一定更流畅。

### 关键帧

关键帧是时间轴上某个时间点的属性状态。Unity 会根据相邻关键帧之间的曲线，计算中间时刻的属性值。

例如：

| 时间点 | 属性值 |
| --- | --- |
| 第 0 帧 | `Position Y = 0` |
| 第 60 帧 | `Position Y = 3` |

如果采样率是 `60 FPS`，第 60 帧就是第 1 秒。播放时，物体会在 1 秒内从 `Y = 0` 移动到 `Y = 3`。

## 打开 Animation 窗口

菜单路径：

```text
Window > Animation > Animation
```

选中场景中的 GameObject 后，Animation 窗口会显示该对象当前可编辑的动画片段。

## Animation 窗口结构

### 顶部播放控制区

| 控件 | 作用 |
| --- | --- |
| Preview | 预览模式开关。开启后可以在编辑器中查看当前动画时间点对应的状态。 |
| Record | 录制模式开关。开启后，修改对象属性会自动写入关键帧；录制模式开启时 Preview 也会开启。 |
| Go to Beginning | 回到动画开头。 |
| Previous Keyframe | 跳到上一个关键帧。 |
| Play | 播放或暂停当前动画片段。 |
| Next Keyframe | 跳到下一个关键帧。 |
| Go to End | 跳到动画结尾。 |
| Current Frame / Time | 显示或输入当前播放头所在帧或时间。 |

常用快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `,` | 上一帧 |
| `.` | 下一帧 |
| `Alt + ,` | 上一个关键帧 |
| `Alt + .` | 下一个关键帧 |

### 顶部工具按钮

| 控件 | 作用 |
| --- | --- |
| Selection Filter | 按当前选择过滤显示的动画属性。 |
| Add Keyframe | 在当前播放头位置，为已经添加到动画中的属性添加关键帧。 |
| Add Event | 在当前播放头位置添加动画事件。 |

`Add Keyframe` 只对已经被动画片段管理的属性有效。如果还没有通过 `Add Property` 添加属性，直接点它通常不会产生预期效果。

### 左侧属性区

左侧主要显示当前动画片段，以及这个片段正在控制的属性。

| 控件 | 作用 |
| --- | --- |
| Clip 下拉列表 | 切换当前对象上的动画片段，也可以创建新的动画片段。 |
| Add Property | 添加要被动画控制的属性，例如 Transform、Renderer、脚本字段等。 |
| 属性列表 | 显示当前动画片段正在控制哪些属性。属性可以展开，直接编辑关键帧值。 |
| Dopesheet | 关键帧模式，适合查看和调整关键帧的时间分布。 |
| Curves | 曲线模式，适合控制属性值随时间变化的节奏。 |

### 右侧时间轴区

右侧是当前动画片段的时间轴，主要用于：

- 拖动播放头，查看任意时间点的动画状态。
- 添加、选择、移动、复制、删除关键帧。
- 缩放时间轴，精细编辑某一段动画。
- 在 Dopesheet 模式下查看关键帧分布。
- 在 Curves 模式下编辑插值曲线和切线。

## 创建 Animation 动画文件

基本流程：

1. 在场景中选中要制作动画的对象。
2. 打开 `Animation` 窗口。
3. 点击 `Create`。
4. 选择 `.anim` 文件保存位置。

保存后，Unity 通常会自动完成以下操作：

- 创建一个 `AnimationClip` 文件，也就是刚保存的 `.anim` 动画片段。
- 创建一个 `Animator Controller` 资源。
- 将新动画片段放入 Animator Controller。
- 给当前对象添加 `Animator` 组件。
- 将 Animator Controller 绑定到该对象的 `Animator` 组件上。

也就是说，你在 Animation 窗口中创建的是动画片段，但 Unity 会顺手搭好一套最基础的 Mecanim 播放链路。

## 创建后窗口会发生什么变化

创建动画片段后，Animation 窗口会出现这些内容：

- 动画片段下拉列表：用于切换当前对象的动画片段，也可以继续创建新片段。
- `Add Property` 按钮：用于添加需要被动画控制的属性。
- 左侧属性轨道：添加属性后，会显示对应属性的关键帧轨道。
- 右侧时间轴：用于编辑当前片段的关键帧和曲线。

如果要制作物体移动动画，通常先添加：

```text
Transform > Position
```

Unity 会为 `Position.x`、`Position.y`、`Position.z` 建立对应的动画曲线。

## 在 Dopesheet 模式编辑动画

`Dopesheet` 是关键帧模式，它关注的是“哪些时间点有关键帧”。如果只是调整关键帧位置、增删关键帧，Dopesheet 会比 Curves 更直观。

### 手动添加属性和关键帧

流程：

1. 点击 `Add Property`。
2. 选择要变化的组件属性，例如 `Transform > Position`。
3. 移动播放头到目标时间点。
4. 修改该时间点的属性值。
5. 点击 `Add Keyframe`，或在录制模式下让 Unity 自动添加关键帧。

示例：

| 时间 | 属性值 | 结果 |
| --- | --- | --- |
| 第 0 秒 | `Position Y = 0` | 物体在起点。 |
| 第 1 秒 | `Position Y = 3` | 物体移动到上方。 |

播放时，Unity 会在两个关键帧之间插值，形成向上移动的动画。

### 使用录制模式添加关键帧

开启 `Record` 后，Unity 会进入自动关键帧模式：

- 移动、旋转、缩放物体会自动记录关键帧。
- 修改 Inspector 中的可动画属性会自动记录关键帧。
- 修改数值、颜色、布尔值等可动画字段也可以被记录。

注意：

- 录制模式下的修改会直接写入当前动画片段。
- 录制结束后建议关闭 `Record`，避免误改动画。
- 如果播放头正好在已有关键帧上，修改会更新该关键帧。
- 如果播放头位于两个关键帧之间，修改通常会在当前位置创建新关键帧。

### 移动关键帧

在 Dopesheet 中选中关键帧后，可以拖动它改变发生时间。

常见规则：

- 拖动某个属性轨道上的关键帧，只影响该属性。
- 拖动汇总行上的关键帧，通常会同时移动该时间点下方关联属性的关键帧。
- 多选关键帧后可以整体移动。

### 添加更多属性

同一个 AnimationClip 可以同时控制多个属性，例如：

- `Transform.Position`
- `Transform.Rotation`
- `Transform.Scale`
- `SpriteRenderer.Color`
- `MeshRenderer.Material` 中部分可动画属性
- 脚本中可序列化且 Unity 支持动画化的字段

例如，先做上移，再添加旋转属性，就能得到一边移动一边旋转的动画。

## 在 Curves 模式编辑动画

`Curves` 是曲线模式，它关注的是“关键帧之间怎么变化”。如果动画运动节奏不自然，例如太匀速、太突然、缺少缓入缓出，就应该切到 Curves 调整曲线。

### Curves 模式适合做什么

Curves 适合处理：

- 非匀速运动。
- 缓入缓出。
- 突然切换。
- 弹性、停顿、加速、减速等节奏。
- 多个属性之间的曲线对比。

Dopesheet 主要看“什么时候有关键帧”；Curves 主要看“关键帧之间怎么变化”。

### 在 Curves 中添加关键帧

可以在曲线区域右键添加关键帧。添加后切回 Dopesheet，也能看到对应关键帧。

编辑曲线时要确认当前选中的是哪条属性曲线，例如：

- `Position.x`
- `Position.y`
- `Rotation.z`
- `Scale.x`

不同属性的数值范围可能差别很大。比如位置可能是 `0 ~ 2`，旋转可能是 `0 ~ 360`。多条曲线叠在一起时，需要适当缩放视图，否则很容易看错正在编辑的曲线。

## 关键帧右键菜单和切线模式

在 Dopesheet 或 Curves 中选中关键帧后，可以右键打开菜单。

### 关键帧操作

| 菜单项 | 作用 |
| --- | --- |
| Add Key | 添加关键帧。 |
| Delete Key | 删除选中的关键帧。 |

### 切线模式

切线决定曲线经过关键帧前后的形状，也就是动画值变化的节奏。

| 切线模式 | 作用 |
| --- | --- |
| Clamped Auto | 自动设置平滑切线，并尽量避免曲线过冲。常用于自然的缓入缓出。 |
| Auto | 旧版自动切线，效果和 Clamped Auto 类似；通常优先使用 Clamped Auto。 |
| Free Smooth | 自由平滑切线，可以手动调整切线方向，同时保持左右两侧平滑连接。 |
| Flat | 将切线设为水平。关键帧附近速度趋近于 0，常用于停顿、缓停、缓起。 |
| Broken | 打断左右切线，可以分别控制关键帧左侧和右侧曲线。 |
| Free | 自由设置切线方向。 |
| Linear | 线性插值，关键帧之间匀速变化。 |
| Constant | 常量插值。值会保持不变，到下一个关键帧时突然跳变，适合开关、枚举、帧动画式切换。 |
| Weighted | 权重切线。可以调节切线影响范围，改变曲线靠近或远离关键帧的程度。 |

### 常用选择

| 目标效果 | 推荐模式 |
| --- | --- |
| 匀速移动 | Linear |
| 自然缓入缓出 | Clamped Auto |
| 突然切换 | Constant |
| 到点停一下 | Flat |
| 左右两侧节奏不同 | Broken |
| 精细控制曲线手感 | Free Smooth / Weighted |

## AnimationClip 参数

选中 `.anim` 文件后，可以在 Inspector 中查看和修改动画片段参数。普通模式和 Debug 模式下能看到的字段不同。

### 常用循环参数

| 参数 | 作用 |
| --- | --- |
| Loop Time | 是否循环播放。开启后，动画播放到结尾会从开头重新开始。 |
| Loop Pose | 是否让循环姿势无缝衔接。常用于走路、跑步、待机等首尾需要连续的动作。 |
| Cycle Offset | 循环周期偏移。用于让循环动画从周期中的某个位置开始播放。值通常按归一化周期理解，例如 `0.5` 表示从循环中段开始。 |

### Debug 模式常见参数

在 Inspector 右上角菜单切换到 `Debug` 模式后，可以看到更多底层字段。对普通 `.anim` 资源，常用关注点是：

| 参数 | 作用 |
| --- | --- |
| Sample Rate | 采样率，也就是动画每秒多少帧。常见值如 `30`、`60`。它会影响时间轴按帧编辑时的精度。 |
| Wrap Mode | 播放结束后的处理方式。常见值包括播放一次、循环、乒乓等。实际运行时还可能受到 Animator 状态机设置影响。 |

补充说明：

- 在 Animation 窗口右上角菜单中也可以显示或设置 Sample Rate。
- `Frame` 通常是让时间轴按帧显示。
- `Set Sample Rate` 是直接修改动画片段的采样率。
- 修改 Sample Rate 会改变帧与时间之间的换算关系。

### Wrap Mode 常见值

| 值 | 含义 |
| --- | --- |
| Default | 使用默认播放模式。 |
| Once | 播放一次后停止在末尾。 |
| Loop | 循环播放。 |
| PingPong | 正向播放到末尾后反向播放，再循环往复。 |
| ClampForever | 播放到末尾后保持最后一帧。 |

在新动画系统中，动画实际如何播放通常还会受到 `Animator Controller`、动画状态、过渡和代码控制影响，因此不要只看 `.anim` 文件本身。

## Animation Event

`Add Event` 可以在动画某个时间点插入事件。当动画播放到该时间点时，Unity 会调用对象上脚本中的指定函数。

常见用途：

- 攻击动画到某一帧时开启伤害判定。
- 脚步落地时播放音效。
- 动画结束前触发特效或隐藏对象。

使用注意：

- 被调用函数通常需要挂在同一个对象或相关对象的组件上。
- 函数名改动后，Animation Event 也要同步检查。
- 不建议把复杂业务逻辑都放进动画事件里。动画事件更适合做时间点触发。

## 使用流程总结

制作一个简单动画：

1. 选中场景中的目标对象。
2. 打开 `Animation` 窗口。
3. 点击 `Create` 创建 `.anim` 动画片段。
4. 点击 `Add Property` 添加要变化的属性。
5. 在第 0 帧设置初始值。
6. 移动播放头到目标时间点。
7. 修改属性值并添加关键帧。
8. 用 Preview 或 Play 预览效果。
9. 如果节奏不对，切到 Curves 调整曲线。
10. 根据需要设置 Loop Time、Sample Rate 等参数。

## 易错点

- 只点 `Add Keyframe` 没有效果：先用 `Add Property` 告诉 Unity 这个动画要控制哪些属性。
- 录制模式忘记关闭：后续随手改 Inspector 值可能会污染动画片段。
- 把帧当成秒：`60` 帧在 `60 FPS` 下是 1 秒，在 `30 FPS` 下是 2 秒。
- 曲线选错属性：Curves 模式下要看清当前编辑的是哪条属性曲线。
- 循环不顺：只开 `Loop Time` 不一定无缝，首尾姿势也要接近，必要时再开 `Loop Pose` 并调整关键帧。
- Sample Rate 乱改：它会影响按帧编辑时的时间换算，改之前先确认动画是否依赖具体帧号。
- Constant 用错：它不会平滑过渡，而是到关键帧时瞬间切换。
