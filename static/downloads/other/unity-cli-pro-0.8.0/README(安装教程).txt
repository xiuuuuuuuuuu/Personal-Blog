1.有两个版本 一个轻量原本 一个Pro版本
2.想安装哪个就直接压缩包也甩给AI对话框并提示:这是一个Skill帮我安装到Codex(或者其他Hardness)


科普:
什么是Skill?
你可以理解为技能包,同时附带给AI查询的手册,比如有了飞机技能包,AI就可以查询飞机的原理,构造,使用方法,维护方法,故障排除方法,等等

没有Skill也可以么?
当然可以,但是没有那么方便了,就和函数一样,你定义好一次以后都去调用即可

什么是UnityBridge?
你可以理解为AI与Unity的桥梁,通过这个桥梁,AI可以与Unity进行交互,比如AI可以控制Unity中的物体,获取Unity中的数据,等等

为什么需要他?
你可以理解UnityEditor是一辆车,早期根本没想过自动驾驶,后来需要自动驾驶了,但是不可能放任AI进到引擎内部乱摸,所以就搞了个UnityBridge来让AI与Unity进行中间桥的沟通
其实还有其他方面的考虑,这里就不多说了
